# 세 타일과 두 종류의 자

각 문제를 시작하면 같은 크기·재질의 타일 세 장을 겹쳐 제공한다. 첫 타일이 위에 보이는 것은 시작 배치일 뿐, 재단용·정답용 같은 역할 구분은 없다.

## 조작

- 타일의 보이는 부분을 끌면 맨 위로 들어 올려 이동한다. 타일끼리는 겹쳐 놓을 수 있으며 벽 충돌은 각각 유지한다.
- 오른쪽 아래 펜 버튼을 켜고 어느 타일이든 재단한다. 가이드 없이 자유곡선도 그릴 수 있다. 펜을 끄고 닫힌 면에 마우스를 올리거나 손가락을 대면 제거 미리보기가 나온다. 탭으로 제거하고 드래그로 이동한다. [펜 입력](pen-input.md)을 참조한다.
- 다른 타일 위에 재단한 타일을 놓고 **위쪽 타일의 실제 가장자리**를 펜으로 따라 그으면 아래 타일에 선이 생긴다. 선만 그어 둔 내부 재단선은 물리적인 본뜨기 가이드로 취급하지 않는다.
- 본뜨기에 사용한 타일도 계속 자르거나 빈자리에 끼울 수 있다. 세 장 중 어느 타일이든 기존 자동 맞춤 조건을 만족하면 완료된다.
- 일자 자는 기존처럼 몸통 이동·끝 손잡이 회전을 지원한다.
- 직각이등변삼각형자는 테두리를 끌어 이동하고 두 예각 꼭짓점의 둥근 손잡이로 회전한다. 구멍 안쪽은 아래 물체를 잡을 수 있다. 세 변 모두 펜 가이드이며, 타일·벽·줄눈 근처에서 스냅된다. 두 손가락으로 이동·회전할 수도 있다.
- Q/E·방향키는 마지막으로 잡은 자에 적용된다. 휠은 포인터 아래 자를 회전한다.
- 되돌리기는 가장 최근 재단·제거를 작업한 타일에 적용된다. 다시 시작은 같은 문제에 새 타일 세 장을 제공한다.

## 상태와 입력

타일마다 재료 마스크·재단선·면 분할·충돌 직사각형·렌더 캔버스·위치를 보관한다. 현재 입력 대상을 나타내는 ID에는 역할 의미가 없다. 표시 순서가 겹친 타일의 선택과 본뜨기에서 위/아래 관계를 결정한다. 마우스로 미리보기만 했을 때는 작업 대상을 바꾸지 않는다.

펜을 가이드에 대면 선을 받을 타일을 정한다. 여러 변이 만나는 꼭짓점에서는 처음 움직이는 방향으로 사용할 변을 고른 뒤 고정하므로, 삼각자의 꼭짓점에서 그리기 시작해도 된다. 타일 가이드에서는 그 타일 아래의 재료를, 자에서는 보이는 가장 위의 재료를 선택한다. 좌표 변환 후 타일 경계에서 생기는 작은 부동소수점 오차를 정리하고, 실제 재료를 우선한 뒤 경계 근처를 보완 검사한다. 왕복으로 문지른 구간도 선에 포함한다. 사선 재단은 실제로 재료가 남아 경계가 되는 구간만 본뜨기 가이드로 보관한다.

자·삼각자와 타일은 펜을 끈 상태에서 화면에서 직접 잡는다. 렌더링과 제거 미리보기는 같은 타일의 마스크를 사용한다. 화면 크기가 바뀌어도 세 장의 재단 상태가 보존되고, 매우 작은 화면에서 복귀할 때는 세 장을 작업대에 다시 놓는다.

## 기존 클리어 보장

랜덤 생성과 정수 벽 충돌 엔진은 그대로다. 각 타일에 동일한 검증 해법을 적용할 수 있고, 다른 타일이나 삼각자를 사용해야만 풀리는 제약은 추가하지 않았다. 다른 타일을 옆으로 치우거나 그대로 둔 채 일자 자와 힌트로 검증된 해법을 재현할 수 있다. 추가된 타일은 이동을 막는 벽으로 취급하지 않는다.

## 확인

`node tests/tile-fit.cjs`는 기존 랜덤 해법·벽 충돌 검사와 함께 다음을 검사한다.

- 처음부터 세 장이 각각 잡히고, 재료와 캔버스가 독립적이며 초기화로 모두 복구됨.
- 실제 자·펜·탭 입력으로 재단한 타일을 다른 타일의 본뜨기에 사용함.
- 본뜨기 후 가이드 타일을 다시 자를 수 있고, 타일 간 작업을 되돌려도 다른 재료를 훼손하지 않음.
- 어느 타일이든 검증 해법으로 재단하고 빈자리에 끌어 자동 완료할 수 있음.
- 두 모바일 크기에서 삼각자 몸통·회전 손잡이·세 변 재단으로 닫힌 면을 만들고 제거함.
- 삼각자의 스냅·이탈·두 손가락 이동/회전, 세 타일의 리사이즈·작은 화면 복귀.

DOM·캔버스는 모의 객체다. 브라우저 연결 도구가 작동하지 않아 이번 변경의 새 브라우저 시각 검증은 수행하지 못했다.
