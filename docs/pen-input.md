# 펜 토글과 자유곡선 입력

오른쪽 아래 펜 버튼을 켜고 타일 위를 바로 드래그한다. 버튼 지름은 게임 화면 가로폭의 25%이며, 플레이 화면 오른쪽 아래에 겹쳐 표시한다. footer는 짧은 안내만 보이는 높이를 유지한다. 버튼 색과 표시등, `aria-pressed`로 켜짐을 알린다. 화면에서 펜 물체를 따로 집어 드는 동작은 없앴다.

- **켠 상태:** 손가락·마우스로 선을 그린다. 타일이나 자가 움직이지 않고, 조각을 탭해도 제거되지 않는다.
- **끈 상태:** 타일·자·삼각자를 직접 이동·회전하고, 닫힌 면을 미리 보고 탭해서 제거한다.
- 자·삼각자·다른 타일 가장자리 근처에서는 선을 맞춰 준다. 가장자리에서 떨어져 그리면 자유곡선이 된다. 한 획 안에서도 가이드에서 벗어나 자유롭게 이어 그릴 수 있다.
- 가이드 꼭짓점에서 시작하면 처음 이동 방향으로 사용할 변을 정한다. 타일 본뜨기는 위쪽 가이드 타일 대신 아래 타일에 그린다.
- 자유곡선 끝이 시작점 근처에 오면 작은 오차를 보정해 닫는다. 닫힌 면은 기존 영역 분할과 제거 규칙을 그대로 사용한다.
- 한 번 드래그한 전체 획을 한 번의 재단으로 저장한다. 되돌리기 한 번으로 해당 곡선의 모든 구간을 지운다.
- 포인터 취소·모드 전환·리사이즈는 아직 저장하지 않은 획을 버린다. 다시 시작·새 문제는 펜을 끈 상태로 시작한다.

자유곡선은 입력 점들을 잇는 폴리라인이다. 브라우저가 묶어서 제공한 중간 포인터 좌표도 읽어 곡선을 보존한다. 타일 좌표로 자르고 정수화한 짧은 선분들을 **한 번의 히스토리 항목**으로 저장하며, 연결된 일직선 구간과 왕복 구간은 합친다. 기존 280×280 재료 래스터와 벽 충돌 엔진은 바꾸지 않았다. 곡선도 실제 타일 재료가 있는 영역에서만 재단에 영향을 준다.

`node tests/tile-fit.cjs`는 새 펜 버튼 입력으로 기존 무작위 해법·세 타일·본뜨기·삼각자를 모두 재검사한다. 추가로 묶인 포인터 입력의 곡선 보존, 가이드 없는 폐곡선의 미리보기/제거, 한 획 되돌리기, 자에서 자유곡선으로 이어 그리기, 펜 모드 중 타일 이동·탭 제거 방지, 입력 취소와 초기화를 확인한다. DOM·캔버스는 모의 객체이며 새 브라우저 시각 검증은 연결 도구 문제로 수행하지 못했다.

## 자유곡선 중 화면 정지 수정

자유곡선의 `stroke.guide`는 의도적으로 `null`이다. 이전 `drawRuler()`의 `stroke?.guide.kind`는 이 상태에서 예외를 던졌다. 화면을 지운 뒤 일자 자를 그리는 도중 멈추므로 그다음 순서인 삼각자가 사라지고, 프레임 끝의 다음 `requestAnimationFrame` 예약도 실행되지 않아 게임판이 멈췄다. DOM 버튼은 계속 동작해도 프레임 루프가 복구되지 않는 증상이 같은 원인이었다. `stroke?.guide?.kind`로 자유곡선을 처리한다.

기존 입력 검사는 드래그 중 화면 갱신을 실행하지 않아 이 오류를 놓쳤다. 실제 프레임 콜백을 실행하며 삼각자 그리기, 다음 프레임 예약, 다시 시작·새 문제 후 그리기와 타일 이동을 확인하는 회귀 검사를 추가했다. 이전 코드에서는 0.5초 안에 해당 TypeError와 세 증상을 재현하고, 수정 후에는 통과한다.

```
TILE_TEST_FILTER='Freehand rendering' node tests/tile-fit.cjs
```
